# fpreader

This repository contains a legacy Java fingerprint reader and image-processing project. It was automatically exported from the Google Code project `fpreader`.

## Source overview

The Java package `br.com.teoni.fpreader` includes fingerprint-processing code such as `FPManager`, a `Griaule` integration class, and image-processing utilities such as `BasicOperations`.

## Working with the project

Inspect the existing project files and imports before selecting a Java toolchain. Fingerprint capture functionality depends on the appropriate external SDK, native integration, and compatible hardware; those requirements must be checked against the source rather than assumed to be bundled. This README does not establish a tested runtime version or build procedure.
